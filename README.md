# 💰 Finance App

## Overview
The **Finance App** is a web-based personal finance management tool built using **Streamlit**, **SQLAlchemy**, and **PostgreSQL**. It allows users to **upload, edit, and manage their expenses and budgets**, providing useful insights into their financial activities.

---

## 🚀 Features

- **User Authentication**
  - Secure login and authentication using hashed passwords.
  
- **Expense Management**
  - Upload Excel files with expense records.
  - Edit existing expenses and add new ones dynamically.
  - Store expenses in a PostgreSQL database.

- **Budget Planning**
  - Create and edit monthly budgets.
  - Track budgeted vs. actual spending.
  - Database-backed budget storage.

- **Financial Analysis**
  - View summaries of income and expenses.
  - Track net balances across different months.
  - Sort and categorize financial data.

- **Streamlit Integration**
  - User-friendly UI built with **Streamlit** widgets.
  - Interactive data tables and forms for smooth data entry.

---

## 🏗️ Tech Stack

| Technology  | Purpose |
|-------------|---------|
| **Streamlit**  | Frontend framework |
| **SQLAlchemy** | ORM for database interactions |
| **PostgreSQL** | Database for storing financial data |
| **Pandas** | Data processing and analysis |
| **Bcrypt** | Secure password hashing |
